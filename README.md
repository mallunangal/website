# ਮੱਲੂ ਨੰਗਲ — Mallu Nangal digital archive

Public heritage website for **Mallu Nangal** (Punjabi: **ਮੱਲੂ ਨੰਗਲ**; also recorded as Malu Nangal), a village in Amritsar district, Punjab, India.

The archive publishes only what can be cited. Census figures, location, and the 1925 government primary school come from public records. Historical narratives, hukamnama text, personalities, and manuscripts are left blank or marked **Demo content** until an editor enters verified material.

Intended public address: [https://mallunagal.com](https://mallunagal.com).

## Care of originals

This website is a catalogue and a reading room, not the only home for village papers. High-resolution manuscript scans should be kept in a separate backup. Families should retain originals.
